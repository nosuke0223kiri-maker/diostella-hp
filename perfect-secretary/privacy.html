プライバシーポリシー

2026年8月12日

本ポリシーは、渡辺康之助（屋号：Diostella）が提供するアプリ「完璧秘書」における利用者情報の取り扱いを定めるものです。

1. データの保存場所（基本方針＝端末内）

記録・設定・履歴などのデータは、原則としてお使いの端末の中に保存されます。開発者がこれらを閲覧することはできません。

2. サーバーに保存されるもの

  • トーク機能のメッセージ・画像（送受信のため。画像は非公開領域＋期限付きの閲覧鍵で表示され、一定期間で自動削除されます）
  • 共有アルバムの写真（非公開領域に保存され、そのアルバムの参加者だけが閲覧できます）
  • SNS・メディアに公開した投稿・作品（公開機能のため。メディア作品は他の利用者に配信されます）
  • メディア作品の購入記録（注文内容・決済状態。当事者だけが閲覧できます）
  • プロフィールの基礎情報（呼び名・生年月日・性別・身長・体重・地域・職業＝すべて任意）：占い・天気・運動などの初期値として使うために保存されます。企業や第三者に提供されることはありません
  • クラウド同期データ（機種変更時の復元のため。記録・設定等）
  • 通知の宛先情報（ロック画面通知のため）
  • これらはクラウドサービス（Supabase）上に、アカウント単位のアクセス制御つきで保存されます

3. Google カレンダー連携（任意機能）

利用者が明示的に連携を許可した場合に限り、本アプリは Google カレンダーの予定を読み取り専用（scope: calendar.events.readonly）で取得し、アプリ内の予定表示にのみ使用します。

  • 取得するのは予定の閲覧に必要な情報（タイトル・日時等）のみで、カレンダーの作成・変更・削除は行いません
  • 取得した予定は表示のために利用者の端末内で扱われ、開発者や第三者に提供・販売されることはありません
  • 広告目的での利用、与信判断への利用、人間による閲覧（法令対応・セキュリティ対応等を除く）は行いません
  • 連携はアプリ内の設定、または Google アカウントの権限設定 からいつでも解除できます
  • 本アプリの Google ユーザーデータの取り扱いは、Google API Services User Data Policy（Limited Use の要件を含む）に準拠します。The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. カメラ・画像加工の扱い

カメラの映像処理・フィルタ加工はすべて端末内で完結します。撮影中の映像や顔のデータが外部に送信・保存されることはありません。サーバーに保存されるのは、利用者が明示的に「保存」「公開」した画像だけです。

5. 取得しないもの

  • 位置情報（天気は選択した地域名をもとに外部の天気サービスへ端末から直接問い合わせます）
  • 連絡先・アドレス帳（共有アルバム等の招待は招待コード方式で、連絡先の同期は行いません）
  • 広告のための個人データ（広告は無料プランにのみ表示されます。あなたの行動を追跡する広告配信・個人データの第三者提供・行動解析ツールはありません）
  • クレジットカード番号（決済はStripe社のページで行われ、カード情報を運営が受け取る・保存することはありません）
  • 氏名・住所等の本人確認情報（現バージョンでは不要です）

6. データの保護（セキュリティ対策）

利用者のデータ（機微情報を含む）は、以下の仕組みで保護されます。

  • 通信の暗号化：アプリとサーバー間のすべての通信は TLS（HTTPS）で暗号化されます
  • 保存時の暗号化：サーバー（Supabase）に保存されるデータは、保存時にも暗号化（AES-256）されています
  • アクセス制御：サーバー上のデータはアカウント単位のアクセス制御（Row Level Security）で保護され、認証された本人（および本人が共有を許可した相手）以外はアクセスできません
  • Google カレンダーデータの保護：予定データおよびアクセストークンはサーバーに保存されず、お使いの端末内でのみ扱われます。トークンは約1時間で自動失効し、認可にはアプリ内に秘密鍵を持たない方式（PKCE）を採用しています
  • アクセスの最小化：運営者による本番データへのアクセスは、障害対応・法令対応等の必要最小限に限定されます
  • インシデント対応：万一データの漏えい等が発生した場合は、速やかに利用者への通知および法令に基づく対応を行います
  • Sensitive data, including Google user data, is encrypted in transit (TLS/HTTPS) and at rest (AES-256), protected by per-account access control, and Google Calendar data and access tokens are stored only on the user's device and never on our servers.

7. データの削除

アカウントとすべてのデータ（サーバー上を含む）は、設定の「アカウントを削除する」でいつでも完全に削除できます。個別の投稿・作品・写真は、各アプリ内の削除操作で削除できます。

8. 外部サービス

  • 天気（気象庁）：機能に必要な最小限の情報（地域コード等）のみが端末から直接送信されます
  • ニュース：運営サーバーが配信元から記事情報を取得して全員に同じ内容を配ります（利用者の個人データは配信元に送信されません）
  • 秘書チャットのAIモード：返答の生成のためにのみ、会話の内容（直近の履歴・添付画像を含む）がAIサービス（Anthropic）へ送信されます。会話がAIの学習に使われることはなく、運営が会話の中身を閲覧することもありません（利用量の管理のため、文章量の数値だけを記録します）。定型文モードの会話はどこにも送信されません
  • Google カレンダー：第3条のとおり、利用者の許可時のみ読み取り専用で連携します

9. 改定

本ポリシーの重要な変更時は、アプリ内でお知らせします。
